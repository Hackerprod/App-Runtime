# API compatibility

This document contains the detailed compatibility inventory migrated from the former
root README. It is intentionally more precise than the project overview: descriptors,
bounded semantics, probe scope, and known omissions belong here.

The runtime uses exact API identity: class descriptor + method name + full method
descriptor. Invoke kind is call-site metadata, not part of the registry key. A missing
API is observable: the runtime emits an `Unimplemented` trace event and throws
`AndroidApiNotImplementedException` rather than silently returning a default.
